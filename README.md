# Albion Eco

Outil d'économie pour Albion Online (serveur Europe) : il lit les prix du marché, calcule chaque recette
dans les villes choisies avec la spécialisation du personnage, et donne une liste d'actions du jour.

- Page : https://shibu7789.github.io/albion-econ/
- Données : fichiers officiels du client du jeu ([ao-data/ao-bin-dumps](https://github.com/ao-data/ao-bin-dumps)),
  reconstruits chaque semaine par `pipeline/update.sh`.
- Prix : [Albion Online Data Project](https://www.albion-online-data.com/), lus depuis le navigateur.
- Consignes de maintenance : `AGENT.md`.
